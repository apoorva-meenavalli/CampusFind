# CampusFind 🎓

CampusFind is a full-stack Lost & Found platform designed for college campuses.

It allows students to report lost and found items, browse reported items, and directly contact the person associated with an item.

---

## ✨ Features

- 🔐 Student registration and login
- 🔒 Protected dashboard and reporting pages
- 🔍 Report lost items
- 🎒 Report found items
- 📋 Browse all lost and found items
- 📞 Contact name and phone number for recovery
- 🗄️ SQLite database
- 🔑 Password hashing using bcrypt
- 🎟️ JWT-based authentication
- 🎨 Responsive React UI
- ⚡ REST API using Node.js and Express
